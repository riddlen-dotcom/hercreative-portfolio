HERCReATIVE PORTFOLIO — QUICK START
====================================

HOW TO OPEN IT
1. Extract/unzip the HerCreative_Portfolio_Code.zip file first.
2. Open the extracted folder named "HerCreative".
3. Double-click index.html.
4. It should open in your web browser. The CSS, JavaScript, profile photo and project preview designs are already linked.

IMPORTANT FILES
- index.html       = page content
- style.css        = colours, layout and responsive design
- script.js        = mobile menu and small interactions
- assets/profile.jpg = your supplied profile picture

KEEP THE FILES TOGETHER
Do not move index.html away from style.css, script.js or the assets folder. If you move one, links can break.

PROFILE PHOTO
Your uploaded photo is already saved as assets/profile.jpg. To change it later, replace that image with another photo and keep the same filename.

CONTACT BUTTON
The email button currently uses hello@hercreative.example as a placeholder. Change it in index.html to the email address you want to use.

PROJECTS
The three project cards are portfolio concepts/sample projects. Update their descriptions as you build real projects.

INTERNET
The site works offline. The optional Google Fonts import may fall back to system fonts without internet.
